# Гербарий и Сито сериалов

Два варианта интерактивной подборки по открытому профилю KACTET на MyShows.

- Гербарий: `index.html`.
- Сито: `sieve.html`.
- Данные, код и обложки: `html-design/`.

Рекомендации и отметки относятся к автору подборки. Дата сохраненных данных показана на страницах. Это статическая публикация: фильтры, поиск, сортировка, тренды и история работают в браузере. Обновление профиля MyShows с сайта не выполняется. Для новых данных нужно опубликовать следующий срез.

GitHub Pages публикует ветку `main`, корневую папку `/`. Весь комплект должен оставаться вместе. Ссылки на MyShows и Google Fonts используют интернет.

Источники: открытые данные MyShows. Изображения принадлежат соответствующим правообладателям.
